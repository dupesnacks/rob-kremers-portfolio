## Evaluation Criteria

| Column | Definition | Why It Matters |
|--------|-----------|---|
| **Supplier Name** | Legal business name + DBA if known | Brand identity |
| **Website/Contact** | Primary contact URL or email | Outreach starting point |
| **GHK-Cu Experience** | Prior cosmetic GHK-Cu projects (Y/N); # of clients | Proves competence; reduces risk |
| **Testing & Documentation** | 3rd-party testing available (Y/N); COA standard (Y/N); batch records (Y/N) | Regulatory + liability + insurance requirement |
| **MOQ (Units)** | Minimum order quantity | Inventory risk; cash flow impact |
| **Lead Time (Days)** | Days from order → ship | Supply chain planning |
| **Est. COGS Range** | $/unit at MOQ (cream/serum) | Profit margin validation |
| **Certifications** | ISO, GMP, FDA registration, organic, vegan, etc. | Quality signal; insurance-friendly |
| **Batch Record Capability** | Supplier provides ingredient list + date-stamped batch docs (Y/N) | Non-negotiable for liability SOP |
| **References** | Prior cosmetic brands willing to vouch (Y/N) | Due diligence on reliability |
| **Outreach Status** | Not Started / Contacted / Responded / Qualified / Hold / Declined | Pipeline tracking |
| **Outreach Date** | When email/call sent | Log |
| **Response Date** | When supplier replied | Log |
| **Notes** | Strengths, weaknesses, red flags, next steps | Context |

## Evaluation Workflow

**Phase 2 Steps:**
1. Send outreach email (template: `outreach/_template.md`) to all 10 candidates simultaneously.
2. Log outreach date in "Outreach" column.
3. As responses arrive, update "Response Date" + "Notes".
4. For responders: populate TBD fields based on replies.
5. Score each on criteria: response speed, MOQ reasonableness, documentation, pricing, certifications.
6. After 1 week: select top 3–5 for detailed calls + sample evaluation.

---

## Supplier Scorecard (Post-Response)

For each supplier, score 1–5 on:
- **Responsiveness** (fast reply, thorough answers)
- **GHK-Cu competence** (prior projects, clear process)
- **Documentation rigor** (COA, batch records, 3rd-party testing)
- **Pricing competitiveness** (COGS within $6–12/unit range)
- **Lead time fit** (4–8 weeks acceptable)
- **References available** (willing to share client refs)

**Qualification threshold:** Score ≥4/5 average to proceed to sample request + reference calls.
